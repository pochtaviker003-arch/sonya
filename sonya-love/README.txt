САЙТ-ПОДАРОК ДЛЯ СОНИ ♡
========================

ЧТО ВНУТРИ
----------
index.html  — сам сайт
style.css   — оформление и анимации
script.js   — комплименты, музыка, сердечки и игра «Найди пару»
qr.html     — генератор QR-кода после публикации сайта
фото/      — сюда добавь 6 своих фотографий
music.mp3  — сюда добавь любимую музыку (этого файла в архиве нет)

КАК ДОБАВИТЬ ФОТО
-----------------
Положи в папку «фото» ровно шесть фотографий. Названия — 1, 2, 3, 4, 5, 6.
Поддерживаются форматы JPG, JPEG, PNG и WEBP — расширение файла менять не нужно.
Например, можно положить 1.png, 2.jpg, 3.webp и так далее. Важно, чтобы номер
каждой фотографии был уникальным и шёл от 1 до 6.

Игра автоматически сделает 12 карточек: по две копии каждой фотографии.
Те же шесть фото появятся в галерее и на главном экране.

КАК ДОБАВИТЬ МУЗЫКУ
-------------------
Положи mp3-файл в корневую папку сайта (рядом с index.html) и назови его music.mp3.
Музыка начнёт играть после нажатия кнопки «Включить музыку» — браузеры не разрешают
автоматически запускать звук без действия пользователя.

КАК ПОСМОТРЕТЬ САЙТ НА КОМПЬЮТЕРЕ
--------------------------------
Открой index.html двойным щелчком в браузере. Для проверки QR после публикации
открой qr.html.

КАК ОПУБЛИКОВАТЬ НА GITHUB PAGES
--------------------------------
1. Создай аккаунт на https://github.com/ (если его ещё нет).
2. Нажми New repository: https://github.com/new
3. Назови репозиторий sonya-love. Для простоты выбери Public и нажми Create repository.
4. Нажми Add file → Upload files и перетащи ВСЁ содержимое этой папки:
   index.html, style.css, script.js, qr.html, README.txt и папку «фото» с шестью фото.
   Если хочешь музыку, добавь music.mp3. Нажми Commit changes.
5. В репозитории открой Settings → Pages.
6. В разделе Build and deployment выбери Source: Deploy from a branch.
7. В Branch выбери main и папку /(root), затем Save.
8. После публикации адрес будет примерно таким:
   https://ТВОЙ-ЛОГИН.github.io/sonya-love/
   Точную ссылку смотри в Settings → Pages → Visit site.
9. Открой адрес сайта, проверь фотографии и музыку.
10. Открой https://ТВОЙ-ЛОГИН.github.io/sonya-love/qr.html
    QR-код заполнится ссылкой на сайт. Нажми «Скачать PNG».

ВАЖНО ПРО ПРИВАТНОСТЬ
---------------------
Сайт GitHub Pages будет доступен по публичной ссылке. Любой, у кого есть ссылка,
сможет открыть фотографии и страницу. Не загружай туда то, что не хочешь публиковать.
